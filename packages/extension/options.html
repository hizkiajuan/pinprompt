Pinprompt

Allow ?

Pinprompt only runs on origins you allow. For a host other than localhost, Chrome asks for access to that host first.

Allowed origins

localhost and 127.0.0.1 work right away. Any other host, such as a dev server on your LAN or tailnet, asks Chrome for access when you add it.

    Shortcuts

    CtrlShiftP
    Start commenting on the page, from anywhere. Same as the toolbar button.
    C
    Toggle comment mode on the page (not while typing in a field).
    CtrlEnter
    Save a comment.
    Esc
    Cancel a comment, stop commenting, close the list.

    Chrome only lets Pinprompt take a pin's screenshot after the toolbar button or the shortcut, and a full page reload takes that away. Use one of them once after a reload.
